# Portfolio

A modern, high-performance portfolio website built with React, Vite, TypeScript, Tailwind CSS, Framer Motion, WebGL Shaders (OGL), and Matter.js physics.

## ✨ Features

- **Ambient Background**: Custom WebGL `ShaderFlow` flowing gradient canvas reacting to dark/light theme and resolution.
- **Interactive Portrait**: `PortraitMorph` WebGL distortion & fluid ripple shader responding to mouse velocity and direction.
- **Draggable Tech Stack**: 2D physics simulation with `Matter.js` featuring draggable, throwable chips and reset functionality.
- **Interactive Contact Button**: Expanding animated contact button with email reveal and one-click clipboard copy.
- **Smooth Navigation**: Floating pill navbar with active route indicator and seamless dark/light mode toggle.
- **Expandable Experience Accordion**: Animated work history with height morphing and backdrop blur overlay.
- **Complete Pages**:
  - `/` (Home)
  - `/projects` (Projects Showcase)
  - `/about` (About & Journey)
- **Silky Smooth Scrolling**: Integrated `Lenis` smooth scroll engine.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Shaders & 3D**: [OGL](https://github.com/oframe/ogl) (WebGL)
- **Physics**: [Matter.js](https://brm.io/matter-js/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)
